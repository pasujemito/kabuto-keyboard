Timing ranges

Dynamic jump-attack

Fresh sets on every play. Alt → Ctrl → release Alt → release Ctrl stays in order. Counts and timings use center-weighted triangular sampling.

A set is a run of jump-attacks facing one way. Between sets, skills may fire and the character may turn around. The starting direction is tapped first; there is no tap after the last set. Direction taps move the character; turn probability does not guarantee position balance.

Timing ranges (milliseconds)
Skills

Each enabled skill gets a chance after each set, with no Alt/Ctrl held. A minimum interval is a cooldown after completion, not a deadline; the first use can occur after the first set. Cooldowns persist across Stop/Start until config reload or reboot.

Variable sequences can still repeat. These settings do not guarantee unique patterns or avoidance of detection.
